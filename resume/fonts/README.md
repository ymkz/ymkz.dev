# BIZ UDPGothic

PDF generation embeds the regular and bold fonts, so it does not rely on system
fonts or network access. Both files are distributed under the SIL Open Font
License; see [OFL.txt](./OFL.txt).

Source: [google/fonts, ofl/bizudpgothic](https://github.com/google/fonts/tree/6ce172f74aa355ea43eb964fa4a91570a4d3064d/ofl/bizudpgothic).
